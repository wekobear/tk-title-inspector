# TK 标题检查 · 试用安排初稿

版本：本地 v0.1。阶段权威当前稿：[Notion实施与验收](https://app.notion.com/p/40d784e7e17e81c9ae90c350e19beae9)；此文件为同版本开发快照。

日期：2026-11-03。当前为个人本地版本，未进行对外推广或团队发布。

先由运营用已确认市场的真实商品标题试用：挑选正常标题、营销表述、品牌/型号大写、数量规格和多变体标题，每类保留正反例及商品事实来源。对比人工判断，记录误报、漏报和原因，不使用“合规率”评价工具。

首轮观察三个问题：能否快速定位需要修改的片段；资料输入与事实复核是否容易完成；批量导入和导出是否保留原文、源行号与人工状态。可以记录单条处理时间，但没有对照基线前不宣称节省比例。

收集样本后再确定首批正式市场、类目及必要检查清单。团队共享前补登录、服务端数据权限及存储；AI启用前确定供应商、允许发送字段、预算和失败降级。对外发布与推广另按用户具体授权执行。

提示易读性试用补记（2026-11-03）：请试用者不展开规则依据，仅凭“位置 + 怎么改”完成促销词、竖线和空格三项修改。记录仍不理解的具体句子与实际操作，不以本次文案修订直接宣称理解率或效率提升。
